## Not reproduced

- Nushell: upstream publishes only raster logos (nushell.github.io assets/nu_logo.ico, logo-contest PNGs); no official vector found and no licence text for the mark was located. The emblem is a generic terminal symbol, not the Nushell mark. Fetch checked 2026-10-06.
- Minecraft (hyperion, optimal-parkour): Mojang's brand guidelines do not allow reproducing its logo or textures; the emblem is a generic isometric block drawn from scratch.
- OpenAI/GPT (gpt4-hals-and-rest-libs): trademark; generic chip + spark symbol instead.
- human-id: generic ID badge (no logo).
